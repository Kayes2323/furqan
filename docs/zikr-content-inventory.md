## Counter eligibility rules

- Only use a counter when the source supplies a clear repetition target.
- For instructional actions (e.g. eating dates, keeping wudu, maintaining family ties), use a checklist/instruction card, not an artificial counter.
- Never infer a target for an unclear line.
- On completion, progress is tied to stable item IDs, not list indexes or titles.
- Any ambiguous wording/count must remain flagged for review and must not be silently published as verified content.
